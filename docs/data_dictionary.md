# Public metadata dictionary

| Field | Meaning | Public release rule |
|---|---|---|
| `record_id` | Stable REC identifier | Publish |
| `text_id` | Textual-entity identifier | Publish |
| `source_id` | Parent-source identifier | Publish |
| `stat_year` / `stat_decade` | Conservative analysis time | Publish |
| `title` | Piece title | Publish after source review |
| `author` | Named author | Publish after source review |
| `parent_source` / `carrier` | Source carrier | Publish after source review |
| `genre` | Normalized writing type | Publish |
| `destination_or_route` | Place label, not full text | Publish only when no privacy concern |
| `geographic_scope` | Geographic scope | Publish |
| `verification_grade` | Evidence quality | Publish |
| `access_status` / `rights_status` | Access and rights state | Publish |
| `source_url` | Original public source URL | Publish only if public and stable |

Never publish full text, long quotations, scans, login-only links, browser sessions, passwords, or institutional database exports in the public release.
